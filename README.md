 StyleHub – Fashion & Apparel E-Commerce Frontend

StyleHub is a fully responsive, modern single-page web frontend for a fashion and apparel e-commerce store. Built with standard HTML5, CSS3, JavaScript (ES6+), and Font Awesome, it provides a complete simulated online shopping experience tailored for men's, women's, and kids' fashion collections.

GitHub Repository:https://github.com/manasaas121/StyleHub-Fashion-Apparel-

✨ Key Features & Functionality

1. Comprehensive Product Marketplace & Catalog:

Browse fashion collections categorized across Men, Women, and Kids.

Real-time search bar and multi-criteria filters (Category, Size, Color, Price Range).

Interactive wishlist toggling on every product card.

2. Interactive Product Detail Page:

Detailed view featuring high-resolution images, rating breakdowns, and item descriptions.

Interactive size and color variant selector.

Popup Size Guide Modal with detailed measurement charts (Chest, Waist).

3. Dynamic Shopping Cart & Order Summary:

Interactive cart with item quantity adjustments and item removal.

Real-time price calculation (Subtotal, Tax, and Final Total).

Working coupon discount engine (e.g., STYLEHUB10 for 10% OFF).

4. Seamless Checkout Process:

Simulated checkout form supporting shipping address entry and payment mode selection (Card, UPI / NetBanking, Cash on Delivery).

Instant order completion notification with generated order reference IDs.

5. User Account & Dashboard:

Simulated user profile management tracking user details.

Order history logging past purchases with delivery status.

Saved wishlist item gallery and personal size preferences log.

6. Brand Story & Store Locator:

About Us Page: Highlights brand heritage, designer collaborations, and sustainable packaging commitments.

Contact Us Page: Interactive contact form, store opening hours, phone support, and flagship store locator details.

7. Responsive Design Guidelines:

Custom color scheme adhering to modern fashion aesthetics: Primary Pink (#E91E63), Dark Navy (#1A1A2E), Gold accents (#D4AF37), and crisp White (#FFFFFF).

Fluid grid layout fully responsive across desktop, tablet, and mobile screens.

🛠️ Technology Stack

HTML5 (Semantic markup & structured layout)

CSS3 (Custom properties/variables, flexbox, grid, animations, and responsive breakpoints)

JavaScript (ES6+) (Single Page Application view management, dynamic rendering, array filtering, state tracking, and UI interaction)

Font Awesome (v6.4.0) (E-commerce icons & UI symbols)

Google Fonts ('Poppins' typography)

🚀 Getting Started & Installation

Since StyleHub is built as a pure frontend web application, no Node.js setup, npm package installation, or backend database is required to run it locally.

Clone or Download the repository to your local machine:

git clone https://github.com/your-username/stylehub-fashion-apparel.git


Open the Project:
Simply double-click the index.html file or open it in any modern web browser (Chrome, Firefox, Edge, Safari).
